Экспорт XML для Битрикс

Формирует каталог товаров в формате CommerceML: файл import.xml и архив изображений import_files.zip в корне сайта.

{$brand_count} брендов {$cat_count} корневых категорий Пакетная выгрузка с прогрессом
  1. Выберите режим. «По категориям» — выгружаются все товары из корневых веток каталога (можно исключить ненужные). «По брендам» — только товары выбранных производителей.
  2. Задайте наценку или скидку в процентах. Например, 0.1 увеличит цену на 0,1%, -5 уменьшит на 5%. Значение 0 — цены без изменений.
  3. Отметьте исключения или бренды на шаге 2. Для категорий галочка означает «не включать эту ветку в экспорт».
  4. Запустите экспорт на шаге 3. Процесс идёт пакетами — не закрывайте вкладку до появления ссылки на файлы.
  5. Импорт в 1С-Битрикс: в админке Битрикс → Магазин → Настройки → Импорт данных укажите URL https://ваш-сайт.ru/import.xml или загрузите файлы вручную с сервера.
📄 import.xml — каталог и цены 🗜 import_files.zip — изображения
Важно: после экспорта файлы перезаписываются в корне сайта. Для регулярного обновления можно настроить cron с CLI-командой плагина или повторять экспорт вручную по расписанию.
